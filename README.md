# 우바 자기소개 웹사이트

운동, 독서, 자기 계발에 관심이 있는 우바를 소개하는 한국어 웹사이트입니다. 관심사와 강점, 배우고 싶은 것, 앞으로의 목표를 한 페이지에서 볼 수 있습니다. 활동이나 작품은 생기면 나중에 추가할 수 있도록 안내 영역을 두었습니다.

## 실행하기

1. Node.js 24 LTS를 설치합니다.
2. 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 내용과 모양 바꾸기

- `src/App.jsx`: 소개 문구와 화면 내용을 수정합니다.
- `src/App.css`: 페이지와 각 영역의 모양을 수정합니다.
- `src/index.css`: 사이트 전체에 적용되는 글꼴, 색상, 기본 모양을 수정합니다.

사이트는 휴대전화와 컴퓨터 화면에 맞춰 표시됩니다. 위쪽 메뉴를 누르면 페이지 안의 해당 소개 영역으로 이동합니다.

## 확인하기

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다.
